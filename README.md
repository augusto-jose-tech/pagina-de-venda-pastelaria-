# 🥟 Página de Venda - Pastelaria Premium

Um protótipo de landing page moderno, responsiva e de alta conversão desenvolvido para a apresentação do cardápio e automação de pedidos de uma pastelaria gourmet.

---

## 🎯 Objetivo do Projeto
Este projeto foi desenvolvido exclusivamente como ambiente de demonstração e testes para portfólio técnico. O foco principal é demonstrar boas práticas de estruturação de código front-end, design limpo orientado à experiência do usuário (UI/UX) e simulação de fluxos lógicos de atendimento.

---

## 🚀 Tecnologias Utilizadas

O desenvolvimento da página foi estruturado utilizando:

* **HTML5** — Arquitetura semântica e acessibilidade.
* **CSS3** — Estilização moderna, variáveis nativas e responsividade (Mobile First).
* **JavaScript (Vanilla)** — Manipulação do DOM e controle dos fluxos internos de simulação.

---

## 📋 Funcionalidades em Destaque

* 📱 **Layout Adaptável:** Experiência visual fluida e otimizada tanto para dispositivos móveis quanto computadores.
* 🛠️ **Simulação de Fluxo:** Interface interativa projetada para testes de usabilidade rápidos.
* ⚡ **Performance:** Carregamento rápido focado em retenção e engajamento visual.

---

## 🔧 Como Executar Localmente

Se você deseja visualizar o projeto na sua máquina de desenvolvimento, siga estes passos:

1. **Clone este repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até o diretório:**
   ```bash
   cd pagina-de-venda-pastelaria
   ```

3. **Inicie o arquivo:**
   * Abra o arquivo `index.html` diretamente em qualquer navegador de sua preferência.
